# 海岸旅行帳本版面

## 範圍
依使用者提供的全頁桌面參考圖調整側欄、海岸背景、四個摘要、支出／還款紀錄與結算區

- 使用 `coastal-main.jsx` 載入既有入口與限定在帳本頁的樣式
- `ProductApp.jsx`、記帳 Modal、金額計算、API、資料庫與依賴均不修改
- 桌面摘要重排為餘額、帳本總支出、成員、待結算
- 重複的管理中心摘要收起，既有側欄管理者入口保留
- 成員應收應付保留可點擊入口，所有成員頭像仍可逐一查看
- 手機保留既有總覽／支出／結算視圖切換與單一記帳 Modal
- 名稱、金額、日期、筆數、權限、已鎖定原因及結算狀態均使用真實資料
- 不把參考圖的金額、結算狀態或頭像寫死為產品介面
- 新增系統文案使用繁體中文、不使用中文句號；不移除使用者資料的標點

## 圖像資產
`public/ledger-coast.webp` 是使用者提供的設計圖中海岸、露營車和木牌的裝飾區域，已移除原圖中凍結的表單、數字、名稱及按鈕

背景經處理、縮放及 WebP 壓縮，配合 CSS 漸隱；不是整張 UI 圖片覆蓋真實功能

兩個小型 SVG 為本次繪製的裝飾圖示，無第三方遠端圖片依賴

參考圖沒有提供原始獨立照片與字型，故圖像修補、字型渲染與文字度量不承諾逐像素相同

## 驗證方式
- 保留全套既有 unit/API 邏輯測試與完整頁面 Modal 手機層級回歸
- 新增三項來源／資產／作用範圍測試
- 新增完整建置版 app 的瀏覽器回歸：九種視窗寬度、四摘要、真實動態資料、成員頭像入口、搜尋、成員篩選、支出／還款頁籤、鎖定原因、帳本設定、應收應付、空帳本、待付款與同一 Modal
- API 與儲存使用模擬，阻擋對外 HTTP(S)，不存取正式帳本
- 本機可用中文字型時檢視桌面／手機截圖；CI 無中文字型時不以缺字截圖宣稱完成中文字寬驗收
- 合併前須通過 pnpm test、pnpm build 與兩組瀏覽器回歸
